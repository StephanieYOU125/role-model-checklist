# Role Model Checklist｜榜樣 10 題檢核

A personal reflection tool for identifying what to learn — and what not to learn — from the people around us.

## 核心概念

> 榜樣不是「我要變成誰」，而是「我要選擇哪些特質成為我自己的一部分」。

這是一個 mobile-first 的個人反思工具，可用來觀察父母、教授、主管、朋友、伴侶或其他重要人物。

## 功能

- 榜樣 Q1–Q9 五分量表與自動平均
- Q10：具體記錄「我想學什麼」
- 記錄「我不想複製什麼」與具體觀察事件
- 三區分析：值得學／可以理解但不必學／明確不要學
- 人物紀錄保存在瀏覽器 localStorage
- iPhone / Safari mobile-first 介面
- PWA manifest 與 service worker，支援離線快取

## 隱私

人物檢核資料預設只存在使用者目前裝置的瀏覽器 localStorage，不會自動提交到 GitHub repository。
